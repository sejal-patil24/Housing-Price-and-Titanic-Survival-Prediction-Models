# Housing-Price-and-Titanic-Survival-Prediction-Models

This project involves building predictive models for two tasks:  
1. Predicting housing prices.  
2. Predicting survival rates for Titanic passengers.  

The models were created using machine learning techniques and optimized for accuracy and performance.

Overview
The project uses data preprocessing, feature engineering, and machine learning to solve two distinct problems:

1. Housing Price Prediction:
   - Built a Gradient Boosting model with 74.6% accuracy.
2. Titanic Survival Prediction:
   - Built a Random Forest model with 80.9% accuracy.

 Key Features
1. Data Preprocessing:
   - Handled missing values in datasets.
   - Performed feature engineering to improve data quality and model performance.
2. Machine Learning Models:
   - Tested various algorithms, including:
     - Gradient Boosting
     - Random Forest
     - Decision Trees
     - SVM (Support Vector Machines)
     - Logistic Regression
   - Achieved the highest accuracy with Random Forest for Titanic survival and Gradient 
     Boosting for housing prices.
3. Model Optimization:
   - Used GridSearchCV for hyperparameter tuning to improve model accuracy.

Challenges Addressed
1. Handled missing and noisy data effectively.  
2. Selected the most relevant features for better predictions.  
3. Compared different machine learning models to choose the best-performing ones.

Results
- Housing Price Prediction: Achieved 74.6% accuracy with Gradient Boosting.  
- Titanic Survival Prediction: Achieved 80.9% accuracy with Random Forest.  

Future Improvements
1. Use deep learning models for more complex feature extraction and prediction.  
2. Incorporate additional datasets for housing prices to improve predictions.  
3. Explore ensemble techniques for better accuracy in survival predictions.
